# Ground Truths

Findings, decisions, and verified facts discovered while working on this
project. AI assistants do not remember previous conversations; this file is how
context survives between sessions.

Record anything **non-derivable**: why a model was rejected, an instrument quirk,
a constraint that turned out to matter, a value someone confirmed by other
means. Do not record things the code or git history already say.

Format:

```
### YYYY-MM-DD: Brief title

What was found, why it matters, and a link to the relevant file or fit_id.
```
